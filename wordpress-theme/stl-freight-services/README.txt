== Description ==

A professional one-page theme for STL Freight Services featuring a modern dark blue and cyan color scheme with full Customizer support for all content sections.

== Installation ==

1. Download the theme folder "stl-freight-services"
2. Compress it into a ZIP file named "stl-freight-services.zip"
   - Make sure the folder is directly inside the ZIP (not nested)
3. Log in to your WordPress admin dashboard
4. Go to Appearance → Themes
5. Click "Add New" → "Upload Theme"
6. Choose the ZIP file and click "Install Now"
7. After installation, click "Activate"

== Customization ==

After activating the theme, go to Appearance → Customize to edit all content:

=== Hero Section ===
- Hero Slide 1, 2, 3: Upload background images (recommended: 1920x1080px)
- Hero Titles 1, 2, 3: Main heading for each slide
- Hero Subtitles 1, 2, 3: Subheading text for each slide

=== Stats Section ===
- Stats Background: Upload background image
- Stat 1-4 Number: The statistic value (e.g., "500+")
- Stat 1-4 Label: Description of the stat (e.g., "Projects Completed")

=== Services Section ===
- Services Image: Side image for the services section
- Service 1-6 Title: Name of each service
- Service 1-6 Description: Brief description of each service

=== Testimonials Section ===
- Testimonial 1-3 Quote: Customer review text
- Testimonial 1-3 Author: Customer name
- Testimonial 1-3 Position: Customer title/company

=== Contact Section ===
- Phone Number: Your contact phone
- Email Address: Your contact email
- Office Address: Your physical address
- WhatsApp Number: For the WhatsApp floating button

=== Social Media ===
- Facebook URL
- Twitter URL
- LinkedIn URL
- Instagram URL

== Recommended Image Sizes ==

- Hero Slides: 1920 x 1080 pixels (16:9 ratio)
- Stats Background: 1920 x 800 pixels
- Services Image: 600 x 800 pixels
- Theme Screenshot: 1200 x 900 pixels
